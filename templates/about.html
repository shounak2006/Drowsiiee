Project Overview

DrowseeAI is a real-time driver drowsiness detection system that runs entirely on CPU. It uses Google's MediaPipe Face Mesh to extract precise facial landmarks per frame, computes the Eye Aspect Ratio (EAR) from six points around each eye, and feeds those values into a temporal fatigue model to classify the driver's alertness state.

The system is designed to be lightweight, interpretable, and deployable on standard laptops — no GPU, no cloud inference, no proprietary hardware required. Typical performance is 25–35 fps on modern consumer hardware.

EAR Methodology

Based on Real-Time Eye Blink Detection Using Facial Landmarks (Soukupová & Čech, 2016).

EAR = (‖p2 − p6‖ + ‖p3 − p5‖) / (2 × ‖p1 − p4‖)
  • p1, p4 — horizontal eye corners
  • p2, p3 — upper eyelid reference points
  • p5, p6 — lower eyelid reference points
  • Open eye typical range: 0.28 – 0.38
  • Detection threshold: EAR < 0.25
Known Limitations
  • EAR accuracy degrades in poor or uneven lighting conditions.
  • Heavy-framed glasses may partially occlude landmarks and reduce accuracy.
  • Extreme head poses (> 45° yaw) cause landmark instability.
  • Detection is per-eye landmark only — no gaze direction inference.
  • Single-driver assumption; multi-occupant scenes are not supported.

  • CNN-based eye classifier (MRL / CEW dataset) for glasses robustness.
